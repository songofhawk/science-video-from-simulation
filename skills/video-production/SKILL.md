# 视频制作

把选题或素材变成一条可以审片、复现和交付的视频。沿用现有时间轴、工具和已确认的稿件、音轨与风格。根据任务推进到用户要求的交付状态。

## 选路线

先用一句话写出「观众看完能说清什么」或「最值得让观众看到什么」。记录受众、目标时长、画幅、语言、指定素材和发布去向。改片时先确认需要保留的版本和本次改动的范围。缺省参数容易调整时，先写下假设并继续做样片。

| 画面的主要任务 | 路线 |
| --- | --- |
| 展示一批已有素材中的高光 | 素材混剪，先审片找可用时间段 |
| 让观众听懂论点、步骤或证据 | 口播剪辑，先定稿和测旁白时长 |
| 让观众看清机制、状态变化或品牌动效 | 代码动画，先做关键帧和代表性样镜 |
| 展示可操作的模型或一次可以复拍的动作 | 网页仿真，先跑通动作和复位，再定机位 |

制作新画面或挑素材时读 [制作路线](references/production-routes.md)。一个项目可以混用路线，每镜记录素材从哪里来、画面要说明什么。

## 从样片到主时间轴

1. 把主题拆成镜头任务。开场先给结果、动作或证据。解释片先说清对象和关系，再用画面展示变化。给重要论断和外部素材记录信源与许可，把仿真、示意、生成镜头和原始记录标识清楚。
2. 先做一小段包含最难镜头的有声预览，顺便验证字幕、字体、构图和声音。在长片或已有审稿安排的项目里，按章节分批制作与审阅。
3. 用稳定的镜头 ID 把旁白、字幕、素材与画面事件连起来。配音用实际测得的起止点落时间轴，素材剪点用源片时间码记录。让字幕和渲染从同一时间轴读取。修改稿件后，重配受影响的句子并重算下游时间。具体写法见 [时间轴与版本](references/timeline.md)。
4. 跑短段检查后再做整片。母版确认后生成所需画幅和语种。横竖版共享镜头意图，分别布置主体、图注和字幕。双语版复用画面素材，按各自录音重新排时间，并检查画面内文字、数字和署名。

## 验收和交付

- 从最终 MP4 验证流规格、时长和完整解码。抽看首尾、转场和关键动作，按手机尺寸检查文字，播放重点片段听人声、原声和音乐。自动转写用于定位疑似漏念、误读和缺句，专名与疑点回听确认。命令和检查项见 [成片验收与发布](references/release-check.md)。
- 交付成片及用户要求的封面、字幕和发布文案。保留可编辑的镜头表、配音稿、素材清单和复现命令。把检查结果和待核项写进交付说明。有现成目录约定时沿用，独立项目可把工程和中间件放 `work/`，把 MP4 放 `final/assets/videos/`。
- 涉及发布时，确认目标账号、版本、封面、文案和平台状态，按用户授权上传。记录公开链接或后台作品编号，并区分已上传、审核中与已公开。
